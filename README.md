# 1a2n-sidekick
Tools and MIDI mapping specific to using the EP136 K.O. Sidekick as a DJ controller in Traktor Pro 4

# Mapping

Gain knobs (turn): loop size selection
Gain knobs (press): enter/exit loop

Hi/mid/lo EQ knobs: high/mid/low adjust (left A, right B)
SHIFT makes them C/D. All have soft takeover.

CUE buttons L/R: Play/Pause decks C/D
SHIFT + CUE buttons L/R: unload decks C/D

1/2 Faders: Volume levels (A/B)
SHIFT + 1/2 faders: volume levels (C/D)
soft takeover on all

FX buttons: play/pause decks A/B
SHIFT + FX buttons: play/pause decks C/D

MOD capacative FX pad thing under the screen: incremental jog turn fast forward (focus deck is the one you click on)
SHIFT + MOD: jog touch on (deck focus is the one you click on)

Vol: Output vol adjust

orange MOD wheel: crossfader position nudge left/right AB/CD
flick it or hold it

Phones: monitor vol adjust

SELECT: change target/function of control (layering)
